## 二、飞书 API 连通性 ✅

| 探测 | 结果 |
|---|---|
| `GET https://open.feishu.cn` | **200** |
| `POST /open-apis/auth/v3/tenant_access_token/internal`（假凭据） | **200** → `{"code":10003,"msg":"invalid param"}` |
| `GET /open-apis/bitable/v1/apps/{token}/tables` | `99991661 Missing access token` |
| `GET /open-apis/bitable/v1/apps/{token}/tables/{tbl}/records` | `99991661 Missing access token` |
| `GET /open-apis/wiki/v2/spaces` | `99991661 Missing access token` |

**结论：完全可用。** 返回 `99991661` 而非 404 说明**路由存在、仅缺凭据**——这是端点存在的确证。

**缺口**：本机不存在任何飞书凭据（环境变量、配置文件均无）。
需要用户提供：
1. 自建应用 `app_id` / `app_secret`
2. 应用需开通权限：`bitable:app`（读写多维表）
3. 两张目标表的 `app_token` + `table_id`

> 建议凭据走环境变量 `FEISHU_APP_ID` / `FEISHU_APP_SECRET`，不落盘仓库。

## 三、AI 上游 ⚠️ 可用但需注意

用户通过 **CC Switch** 本地代理接入，调用链：

```
脚本 → https://agentrouter.org/v1/chat/completions → deepseek-v4-flash
```

### 踩坑全过程（重要）

| 尝试 | 结果 |
|---|---|
| `curl` 无特殊头 | ❌ `unauthorized client detected` |
| 加 `Authorization: Bearer <key>` | ❌ 同上 |
| **加 Claude Code 客户端指纹头** | ✅ **成功返回** |

必须同时带上：

```
user-agent: claude-cli/2.0.0 (external, cli)
anthropic-version: 2023-06-01
anthropic-beta: claude-code-20250219
```

### 其他实测要点

- 模型 `deepseek-v4-flash` 是**推理模型**，响应含 `reasoning_content`
- `max_tokens=20` 时出现 `finish_reason: "length"` 且 `content` 为空 —— **预算全被推理吃掉**。抽取任务建议 ≥4096
- 凭据位置：`~/.cc-switch/cc-switch.db` → `providers` 表 → `is_current=1` → `settings_config.env.ANTHROPIC_AUTH_TOKEN`
- 观测到的成本：约 **$0.015 / 次调用**（中转加价后，日志 `proxy_request_logs` 可查）

> ⚠️ 这是**第三方中转服务**，非 Anthropic 官方。风险见 `ADR/0002`。

> 🔑 **这是唯一能填 `actual_bar` / `return_offer` / `wlb` / `interview_content` 的源。**
> Reddit 和 LinkedIn 都填不上这几个字段。

**使用要点**：
- **必须开 `--ocr`** —— 金融内容大量在图片里（JD 截图、岗位表格），纯正文会漏一半
- `--filter` 支持 `sort` / `note_type` / `publish_time` / `search_scope` / `distance`
- 用**独立 Chrome 配置** `~/.socai/chrome-profile`，与用户日常 Chrome 不同
  → 扫码必须扫 socai 自己弹的窗口
- 产物在 `~/.socai/runs/{ts}_{cmd}/`；`output.json` 报 `reason: "login_required"` = 需重新扫码
- 抓取要放缓、不并发，避免触发风控

#### 1. Reddit RSS —— 英文一手经历主力源 ⭐

```
https://www.reddit.com/r/{subreddit}/.rss
```

- 实测 `r/FinancialCareers/.rss` → **200，47,105 bytes，25 条 entry**
- 每条含：`<title>` `<link href>` `<updated>` `<content type="html">`（**全文 HTML 正文**）
- 解析出的真实样本：
  - 「2025 Compensation Megathread」— 薪资汇总帖，正文含大量薪资自述
  - 「About to start my first for real for real finance job!」— 2026-09-11
  - 「Join our growing /r/FinancialCareers Discord server!」

> 🔑 **Reddit 的 JSON API（`/new.json`、`/search.json`）返回 403，但 RSS 端点完全可用。**
> 这是整个 MVP 成立的前提。切不可因为 JSON 被封就放弃 Reddit。
> ⚠️ 连续请求会触发 **429**（实测 `/new.rss` 立即请求即被限流），需 ≥5s 间隔。

#### 2. LinkedIn 公开岗位 —— JD 侧质量最高 ⭐

- 每张卡片可稳定解析出：职位名 / 公司 / 地点 / 发布时间 / 详情 URL
- 实测样本（`keywords=investment banking&location=Hong Kong`）：

> 这是唯一能稳定提供**公司+岗位+城市+时间**四要素齐备的源，直接喂给表 1 的 `company` / `role` / `city` / `published_at` / `source_type=job_posting`。

#### 3. eFinancialCareers —— 金融垂直招聘

- `efinancialcareers.com` → **200，751 KB**；`efinancialcareers.cn` → **200，859 KB**
- 首页含 19 个 `/jobs/*` 链接 + 2 段 `ld+json`（schema.org Organization）
- 判断：可用，但需写 HTML 选择器，**MVP 第二轮再做**

#### 4. Bing 搜索

- `bing.com/search?q=...` → **200，122 KB**，133 个链接
- 全部结果走 `r.bing.com/ck/a?...&u=a1<base64>` 跳转 → 需 base64 解码还原真实 URL
- 判断：可用的泛化补源，**MVP 第二轮**

#### 5. 牛客网

- 首页 `nowcoder.com` → 200
- 但 `/api/discuss/getDiscussList` → 返回 **HTML 壳而非 JSON**，是伪 API
- 判断：**需逆向真实 XHR 才有价值**，MVP 暂不纳入

## 五、结论：MVP 的信息源画像

**可支撑的**：
- ✅ **中文一手面经 / 留用 / 薪资经验（小红书，经 socai）** ← 2026-09-13 补上
- ✅ 英文区一手求职经历（Reddit 4 个板块）
- ✅ 香港 + 海外公开招聘 JD（LinkedIn + eFinancialCareers）
- ✅ 泛化搜索补源（Bing）

**仍然撑不起的**：
- ❌ 一亩三分地 / WSO 这类**长篇深度面经帖**（Cloudflare，socai 也不支持）
- ❌ 结构化 JD 平台直连（BOSS直聘 / 猎聘 / 51job 均有强反爬）
- ❌ 脉脉 / 看准网薪资爆料（未验证）

### 覆盖画像（2026-09-13 修订）

> **中文一手经历**（小红书：面经 / offer / 留用 / 薪资 / 真实背景）
> 　+ 英文一手经历（Reddit）
> 　+ 公开招聘 JD（LinkedIn，港/海外）
> 　− 长篇深度面经（一亩三分地 / WSO，确实拿不到）

`actual_bar` / `return_offer` / `wlb` / `interview_content` 这几个最关键的字段，
**已由小红书补上**，这是本报告初版最大的判断失误。

初版写的是「中文一手面经全部被封，是硬缺口」——**错误**。

教训已记入 `D:\xhs-teardown\` 的同类经验：**判定一个源不可用前，先看 socai 支不支持。**
