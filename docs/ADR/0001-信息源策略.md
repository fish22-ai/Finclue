## 【2026-09-13 修订】原决策被推翻

**原结论「中文一手内容源几乎全线不可达」是错的。**

错误原因：我用裸 `curl` 探测可达性，小红书返回 302 登录墙 → 我判定它不可用。
但实际上**用户本机早已装好专用抓取工具 `socai`**，能用本人账号完整抓取小红书，
包括正文、逐图 OCR、评论。

> 用户指出：「国内金融市场还是得看小红书」

修正后的源优先级：

| 优先级 | 源 | 角色 | 理由 |
|---|---|---|---|
| **P0** | **小红书（经 socai）** | **中文一手经历** | **唯一能填 `actual_bar` / `return_offer` / `wlb` / `interview_content` 的源** |
| P0 | Reddit RSS | 英文一手经历 | RSS 端点可用（JSON API 403） |
| P0 | LinkedIn guest jobs | 公开招聘 JD | 四要素齐备（公司/岗位/城市/时间） |
| P2 | eFinancialCareers / Bing | 补源 | 可用但需额外解析工作 |

**仍然不可用**（这些是真的封了，socai 也不支持）：
一亩三分地、Wall Street Oasis、知乎、Glassdoor、Indeed、猎聘。

**合规边界相应调整**（用户已确认）：
socai 以本人账号、受管浏览器、人类速度浏览公开帖子，属正常登录访问，
**不属于反爬绕过**。除此之外不新增任何登录类数据源。
Cloudflare 拦截类仍然直接放弃，不做绕过。

## 原第 1 节（2026-09-12，结论已作废，保留以记录决策过程）

> ⚠️ 以下内容基于错误的可达性判断，**不要据此决策**。保留是为了记录教训。

### 背景

需求要求覆盖券商、投行、行研、PE/VC、公募/私募、资管、银行、信托、保险、量化、金科、财资、风控、财会，
并优先抓取「带明确公司/岗位/时间的 offer、WLB、薪资、真实录取背景、面经」。

2026-09-12 对候选源做了全量**裸 HTTP** 实测，结果是：
**中文一手内容源几乎全线不可达。**

- 一亩三分地、Wall Street Oasis → Cloudflare 403
- 知乎、小红书 → 登录墙
- 牛客 → 伪 API
- Glassdoor、Indeed、猎聘 → 403 / 无法连接

而两个"意外可用"的源撑起了局面：
- **Reddit RSS**（JSON API 被封，RSS 却通）
- **LinkedIn guest jobs API**（无需登录，结构化）

### 原决策（已作废）

MVP 首轮只启用 3 个源，且优先"结构化程度高"而非"覆盖广"：Reddit RSS、LinkedIn guest jobs，
eFinancialCareers/Bing 作补源。

### 原「明确放弃」条款（部分仍有效）

1. **不绕过任何反爬。** 不接打码平台、不用代理池、不伪造浏览器指纹。
   Cloudflare 拦截 = 该源不可用，记录在案，不再尝试。 ← **这条仍然有效**
